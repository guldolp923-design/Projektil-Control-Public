## PROJEKTIL Control v1.0.22

### Version 1.0.22
- Emergency sendet jetzt nur noch einen einzelnen OSC-Befehl `/notaus` an Pixera.
- Beim Emergency werden die Endstufen nicht mehr automatisch gemutet.
- Optionales Monitoring für den Notaus-Schalter mit der IP 192.168.1.99 wurde ergänzt.
- In den Einstellungen kann jetzt aktiviert werden, ob die Installation einen Notaus-Schalter verwendet.

### Changelog
- Emergency-Aktion auf OSC `/notaus` umgestellt
- Automatisches Muten der Endstufen im Emergency-Pfad entfernt
- Notaus-Schalter als optionales Monitoring-Device ergänzt
- Installationsschalter für Notaus in den Einstellungen ergänzt

- Windows Installer (NSIS)
