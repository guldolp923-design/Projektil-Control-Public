# PROJEKTIL Control v1.0.23 — Release Notes

**Release Date:** August 10, 2026

## ✨ Features

### Improved Device Monitoring
- **ICMP Ping für Interactive Devices**: Scanner (192.168.1.34/35), Interactive PC (192.168.1.36) und Art-Net Gateways nutzen jetzt echtes **ICMP Ping** (wie `ping` im CMD) statt TCP Port-Checking
- **Optimierter Polling**: Art-Net Gateways werden jetzt **nur alle 30 Sekunden** gepingt statt alle 10 Sekunden (reduziert Netzwerk-Traffic)
- **Zuverlässigere Erreichbarkeitsprüfung**: ICMP Ping funktioniert auch, wenn Geräte keinen HTTP-Server auf Port 80 haben

## 🔧 Technical Changes
- Neue Rust-Funktion: `icmp_ping()` nutzt Windows `ping.exe`
- Neue Frontend-Funktion: `icmpPing()` ruft die Rust-Funktion auf
- Separate Polling-Funktion: `pollArtNetGateways()` mit 30-Sekunden-Intervall
- Startup-Checks angepasst für Art-Net Geräte

## 🐛 Bug Fixes
- Fehlerhafte Offline-Status bei Scanner und Interactive PC behoben

## 📝 Notes for Operators
Alle neuen Features sind automatisch aktiviert. Keine Konfigurationsänderungen erforderlich.
