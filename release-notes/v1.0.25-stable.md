# v1.0.25 – Remote Emergency Trigger via UDP

## Neue Funktionen

- **Ferngesteuerte Emergency-Auslösung**: PROJEKTIL Control lauscht jetzt auf UDP Port 9001 und reagiert auf OSC-Befehle von externen Geräten (z.B. physischer Emergency-Schalter unter 192.168.1.99).
- Wenn der Befehl `/emergency_pressed` auf Port 9001 eingeht, wird das UI sofort in den Emergency-Modus versetzt – als ob der Emergency-Button manuell gedrückt worden wäre.
- Nach Eingabe des Entsperr-Codes wird automatisch ein OSC `/emergency_reset` (int 1) an 192.168.1.99:9000 gesendet, um den physischen Schalter zurückzusetzen.

## Technische Details

- Rust UDP-Server auf `0.0.0.0:9001` (läuft im Hintergrund ab App-Start)
- OSC `/emergency_pressed` löst Tauri-Event `emergency-pressed-remote` aus
- Frontend fängt das Event ab und ruft `confirmEmergency()` auf
- Neuer Tauri-Befehl `send_emergency_reset_osc()` sendet `/emergency_reset` an 192.168.1.99:9000
- Reset wird nur gesendet, wenn Emergency durch Remote-Schalter ausgelöst wurde
